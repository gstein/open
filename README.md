# open
Home for Greg's open source work. Tools, writings, other.

## Python utilities

- `logsetup.py` — small helper for consistent `basicConfig` + plain/colored formatters. Symlink it into your script directories and `import logsetup`.
- `llm/` — LLM utilities (`llm_utils.py`, `stopwatch.py`, `log_usage.py`). Symlink the pieces you need.
- `pbar.py` — terminal progress bar.
